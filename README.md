# CampusFindr

CampusFindr is a FUPRE-focused lost-and-found prototype. It reuses the visual language of the original SecureChat project while pivoting the product toward structured item reporting, searchable campus listings, private recovery conversations, and privacy-aware call requests.

## Test locally in VS Code

1. Open this folder in VS Code.
2. Open **Run and Debug** and select **CampusFindr: local development**, or run the task **CampusFindr: start local app**.
3. Open the local URL shown by the development server, normally `http://localhost:3000`.
4. Click **Login** on the prototype screen; this first build uses local demo state and does not need Supabase credentials.

The prototype currently includes the dashboard, browse/search/filter flow, lost/found report forms, reports list, item details modal, private chat mock flow, call-request privacy message, responsive layout, and VS Code tasks. Supabase persistence and production authentication are intentionally left for the next phase after the UI direction is tested.

## Formal project topic

**Design and Implementation of a Web-Based Lost and Found Management System for FUPRE**
